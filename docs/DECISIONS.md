# Registre des décisions : Nid

Suivi de toutes les décisions du projet. Une ligne par décision ; les décisions structurantes ont leur ADR dans `docs/adr/`. Mettre ce registre à jour à chaque décision nouvelle ou changée (ne pas effacer : barrer ou marquer « remplacée par n° … »).

Statuts : **validée** (dite explicitement par l’utilisateur), **validée avec le plan** (comprise dans le plan validé le 25 novembre 2026), **à trancher**.
